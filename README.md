# Nyontra SDK (v2.0 Gateway)

Professional SDK for interacting with the Nyontra Blockchain through the Dev Portal Gateway.

## Features
- **Double-Gate Security**: Sensitive operations require both a Developer API Key and a User's cryptographic signature.
- **Admin Kill-Switch**: Support for gateway-level feature toggles.
- **Simplified API**: One class to manage all interactions.

## Installation
```bash
npm install @nyontra/sdk
```

## Quick Start

```javascript
import { NyontraSDK } from '@nyontra/sdk';

const sdk = new NyontraSDK({
  apiKey: 'nyon_sk_your_api_key_here',
  baseUrl: 'https://api.nyontra.com' // Your portal backend URL
});

// 1. Validate an address
const validation = await sdk.validateAddress('0x...');
console.log('Is valid:', validation.valid);

// 2. Check Balance (Requires User Signature)
// Note: userSignature is generated by the user's wallet signing a message
const balance = await sdk.getBalance('0xUserAddress', 'user_signature_hex');
console.log('Balance:', balance.amount);

// 3. Lock NYON (Requires User Signature)
const lockTx = await sdk.lock(100, '0xUserAddress', 'user_signature_hex');
console.log('Lock TX Hash:', lockTx.hash);

// 4. Get Block Info (Admin Toggled)
try {
  const block = await sdk.getBlockInfo(1500);
  console.log('Block Data:', block);
} catch (error) {
  // If admin has disabled this feature, this will throw an error
  console.error(error.message);
}
```

## Methods

| Method | Description | Requires Signature? |
|--------|-------------|---------------------|
| `lock(amount, address, signature)` | Lock NYON | Yes |
| `unlock(amount, address, signature)` | Unlock NYON | Yes |
| `transfer(amount, to, signature)` | Transfer NYON | Yes |
| `getBalance(address, signature)` | Get Account Balance | Yes |
| `getTransactionStatus(txid)` | Check TX Status | No |
| `validateAddress(address)` | Check address format | No |
| `getBlockInfo(height)` | Get Block Data | No (Admin Kill-Switch) |

## Error Handling
The SDK throws descriptive errors for:
- Invalid API Keys (401)
- Disabled Features (403)
- Blockchain Timeout (504)
